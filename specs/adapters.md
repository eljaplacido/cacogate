# Adapters (AD, CC, RP)

Crate `cacogate-harness`: `src/lib.rs` (`enforcement`), `src/wrap.rs` (`cacogate run` envelope), `src/claude.rs` (Claude Code hooks), `src/repo.rs` (`probe`).
Crate `cacogate-cli`: `tests/run.rs` (`cacogate run` binary with the daemon unreachable). TS mirror: `adapters/src/core/client.ts`.

- **AD-001** — While the gate is in shadow mode, the adapter shall map every verdict to `defer` (Rust and TS); the TS mapping shall also defer `allow` and never defer held verdicts in enforce mode. _Test:_ `crates/cacogate-harness/src/lib.rs` `test_ad001_shadow_never_interferes`; `adapters/test/adapters.test.ts` `AD001 enforcement mapping matches Rust`
- **AD-002** — While the gate is in enforce mode, the adapter shall map every non-executing verdict to something other than `defer`, and `allow` to `defer`. _Test:_ `crates/cacogate-harness/src/lib.rs` `test_ad002_enforce_mapping_never_runs_held_actions`
- **AD-010** — When `cacogate run` joins argv into a command string, it shall leave plain words bare and single-quote words containing spaces, metacharacters, globs, apostrophes (escaped as `'\''`) or the empty string. _Test:_ `crates/cacogate-harness/src/wrap.rs` `test_ad010_shell_join_quotes_only_what_needs_it`
- **AD-011** — When `cacogate run` builds an envelope, it shall use tool `bash`, the joined argv as `command`, `interactive = false`, and a `sha256:` action digest. _Test:_ `crates/cacogate-harness/src/wrap.rs` `test_ad011_wrapped_envelope_is_a_non_interactive_bash_call`
- **AD-012** — If the daemon is unreachable in enforce mode and the kernel fallback finds an invariant breach, then `cacogate run` shall exit 126 without running the command, name the rule (`INV-VCS-001`) and `PRV-GATE-001` on stderr, and spool a `daemon_unreachable` record to `spool.jsonl`. _Test:_ `crates/cacogate-cli/tests/run.rs` `test_ad012_run_refuses_invariant_breach_with_daemon_down`
- **AD-013** — While the daemon is unreachable, `cacogate run` shall run read-class commands in enforce mode and return the child's exit code, refuse other commands with 126, and in shadow mode run the command and return its exit code (127 when the program does not exist). _Test:_ `crates/cacogate-cli/tests/run.rs` `test_ad013_run_passes_through_the_child_exit_code`
- **AD-014** — When `cacogate run` wraps `sh -c '<script>'`, it shall judge the script body (a `curl | sh` body is refused with 126 citing `INV-NET-001`). _Test:_ `crates/cacogate-cli/tests/run.rs` `test_ad014_run_judges_sh_c_bodies`
- **AD-015** — While in shadow mode, `cacogate run` shall run a command whose text contains an invariant breach and return the child's exit code. _Test:_ `crates/cacogate-cli/tests/run.rs` `test_ad015_run_in_shadow_mode_never_interferes`
  _Notes:_ the body checks only exit 0 for `exit 0; git push --force origin main`; it does not assert that a blocking verdict was computed (or logged) for it.
- **CC-001** — When a Claude Code `PreToolUse` payload arrives, the adapter shall build an envelope carrying its session ID, tool name and tool input, marked interactive, whose action digest recomputes identically. _Test:_ `crates/cacogate-harness/src/claude.rs` `test_cc001_pre_payload_to_envelope`
- **CC-002** — If a `PreToolUse` payload is missing fields or is not an object, then the adapter shall return an error rather than panic. _Test:_ `crates/cacogate-harness/src/claude.rs` `test_cc002_missing_fields_are_errors_not_panics`
- **CC-003** — When a `PostToolUseFailure` payload arrives, the adapter shall record the execution as an error; for `PostToolUse` it shall record it as not an error. _Test:_ `crates/cacogate-harness/src/claude.rs` `test_cc003_post_failure_is_error`
- **CC-004** — The adapter shall emit no `PreToolUse` response for `defer`, and for `deny` a `hookSpecificOutput` with `permissionDecision = "deny"` and `hookEventName = "PreToolUse"`. _Test:_ `crates/cacogate-harness/src/claude.rs` `test_cc004_response_shapes`
  _Notes:_ the `ask` response shape is not checked.
- **CC-005** — The generated hooks configuration shall register a `command` hook for each of `PreToolUse`, `PostToolUse` and `PostToolUseFailure`. _Test:_ `crates/cacogate-harness/src/claude.rs` `test_cc005_hooks_config_covers_three_events`
- **RP-001** — When probing a directory inside a git repository, the probe shall walk up to the repository root and report the root, the current branch from `HEAD` (including slashed branch names) and the head commit. _Test:_ `crates/cacogate-harness/src/repo.rs` `test_rp001_finds_branch`
- **RP-002** — When probing a directory that is not inside a repository, the probe shall not report that directory (or anything under it) as a repository root. _Test:_ `crates/cacogate-harness/src/repo.rs` `test_rp002_no_repo`
  _Notes:_ the test tolerates an enclosing repository above the tempdir, so it does not strictly pin "no repo → none".
- **AD-016** — If the Claude Code plugin launcher cannot find the `cacogate` binary, then it shall exit 2 (block) when enforce mode is set by `CACOGATE_MODE` or by an uncommented `mode = "enforce"` line in the config file, or when `CACOGATE_MODE` holds any value other than `shadow`, and exit 0 when the mode is shadow or unset. _Test:_ `crates/cacogate-cli/tests/plugin.rs` `test_ad016_plugin_launcher_fails_closed_without_binary_in_enforce_mode`
